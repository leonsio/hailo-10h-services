# API and protocols

HTTP/OpenAI/SSE/WebSocket and MCP composition; Wyoming/MQTT adapters, browser Playground/Monitoring/Settings routes, authenticated monitoring/settings APIs and TLS helpers. `app.py` accepts app-scoped runtime factories and starts resident model initialization in the background so HTTP diagnostics remain available during startup. `process_app.py` supplies process runtimes without global substitutions. Domain planning belongs in `assistants/`.
